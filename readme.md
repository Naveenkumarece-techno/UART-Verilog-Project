# UART Verilog Project

## Overview
This project implements a simple UART (Universal Asynchronous Receiver Transmitter) transmitter using Verilog HDL. UART is a widely used serial communication protocol in embedded systems, microcontrollers, and SoC designs for transmitting data between devices.

The design includes RTL implementation of a UART transmitter and a Verilog testbench for functional verification. The transmitter sends serial data based on clock-driven operation, and the functionality is verified through behavioral simulation in Vivado.

This project helped in understanding:
- Verilog HDL coding
- UART communication basics
- RTL design methodology
- Testbench development
- Simulation and waveform analysis

## Features
- UART Transmitter Design
- Serial Data Transmission
- RTL Design using Verilog HDL
- Functional Verification using Testbench
- Behavioral Simulation and Waveform Analysis

## Tools Used
- Verilog HDL
- Xilinx Vivado Simulator

## Folder Structure
- rtl -> RTL source code
- tb -> Testbench files
- sim -> Simulation waveform screenshots

## Simulation
Behavioral simulation was performed in Vivado to verify UART transmission functionality and waveform timing.
